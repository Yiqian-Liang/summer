# 搜索完善与项目检查记录（2026-09-07）

本文件用于替代历史占位链接，汇总“已完成”和“待优化”。

## 已完成

1. 本地检索 + 在线补充分离
- 搜索参数统一：`q`、`source`、`page`、`limit`。
- 查询在首屏才触发在线补充，保留缓存/失败状态。

2. 约束与验证
- 查询长度、页码、`limit` 做严格校验。
- 查询必须有意义；`sort=resume` 严格要求已启用简历。
- `source` 白名单与平台别名映射。

3. 去重与排序
- URL/标题+机构去重。
- 仅在第一屏内执行语义重排，防止长列表开销。

4. 行为反馈闭环
- 收藏、隐藏、恢复、清除历史。
- 行为仅用于本用户，不回写跨用户模型。

5. 简历匹配打通
- `sort=resume` 支持在搜索/API 列表中按匹配证据排序。
- 简历匹配结果支持证据展示（`resume_match`）。

6. 入口闭环增强
- 收藏可管理阶段、提醒天数与备注，并在列表中联动截止提醒。
- 邮件起草、附件与帖子创建与搜索结果互通。

## 待优化项

- 用户反馈指标再细化：
  - 站内点击到邮件发起转化率
  - 招募帖到外部机会动作为是否申请（需用户授权采集）
- 搜索来源与质量统计的自动化回归基线
- `INFORMATIONAL_FILTERS` 源边界策略（如 `scholar`）持续调参

## 与社区/邮件生态联动

- 招募帖与站内邮件可减少外部跳转；仍需持续：
  - 模块化首页动线（推荐 → 机会 → 邮件 → 社区）
  - 新用户首屏引导（为何可信、如何投稿、如何发邮件）
  - 定期清理无效外链与过期项目
