# 邮件与社区功能交付

## 已完成

- 项目详情和搜索结果新增邮件起草入口，进入登录用户专属的邮件工作台。
- 免费中英文模板、语气选择、真实姓名/学校/兴趣/背景填写、编辑、保存、复制、继续编辑已有草稿。无需连接邮箱即可使用。
- AI 邮件默认关闭；管理员启用且用户主动选择后才调用 Gemini，失败时明确提示并使用模板。个人背景不会作为外部网页搜索词。
- 最多连接 5 个邮箱：QQ/网易应用专用密码，学校/其他邮箱自定义 SMTP，Google/Microsoft OAuth。授权信息在服务器加密保存。
- 站内发送前完整核对发件人、收件人、主题、正文；一次一位收件人。保存版本校验与发送状态保护避免多页覆盖及重复发送；网络结果不确定时不自动重发。
- 附件支持上传、列表、下载、移除、发送前核对及真实 SMTP/OAuth 发送；每封最多 5 个、合计 2 MiB，每用户存储 20 MiB。附件不交给 AI。
- 关联机会的邮件仅在邮箱服务明确返回 `sent` 时自动收藏并标记“已联系”，生成七天后的下一步；`failed/unknown` 不改变申请阶段。
- 招募、经验分享、讨论三类帖子；自己的草稿、编辑、发布、下架，公开分类/关键词搜索、分页、评论与删除本人评论。
- 已发布招募同时进入机会搜索并可起草联系邮件；经验、讨论、草稿、下架内容不会混入机会搜索。发布者身份明确标为未核验。
- 补充登录密码哈希升级、私有页面禁缓存、CSRF 校验、安全登录跳转、密码重置后退出旧会话；修复重置令牌未正确失效的问题。
- 账号恢复邮件尚未配置时明确提示，默认不打印重置链接，也不谎报已发送。原本本机开发恢复方式需要显式开启 `ENABLE_DEV_PASSWORD_RESET=1`。
- 注册、发帖、评论与 AI 请求使用 SQLite 持久化限流；维护采集接口由 `ADMIN_API_TOKEN` 单独保护。项目匹配 AI 还需 `ENABLE_MATCH_AI=1`，默认只运行本地证据分析。

## 验证

- 全量离线测试覆盖搜索回归、三种帖子可见性、身份隔离、附件、草稿版本冲突、CSRF、输入转义、SMTP TLS/网络地址校验、OAuth 状态与令牌刷新、失败与不确定发送状态。
- 浏览器实际操作：临时账号登录 → 中文免费起草 → 保存 → 查看完整发送确认 → 取消发送；经验帖发布 → 公开详情 → 评论显示。页面无脚本错误。
- 浏览器测试使用独立临时数据库和模拟邮箱，发信网络被禁止；单元测试均模拟邮件/AI网络，没有授权真实邮箱或发送任何真实邮件。
- 测试使用临时数据库，不向现有账号写入草稿、帖子或申请记录；新表在下次正常启动时自动创建。

## 启用真实邮箱

具体配置与官方链接见项目 README 的“邮件与社区配置”。

1. 安装更新后的依赖，设置并备份持久的 `MAIL_ENCRYPTION_KEY`。不要随服务器重启重新生成。
2. 设置正确的 `SITE_BASE_URL`；公开站点使用 HTTPS。
3. Google/Microsoft 在各自平台登记授权应用，填写 `.env` 的客户端 ID/Secret，并登记精确回调地址；Google 需启用 Gmail API。
4. QQ/网易使用邮箱服务商提供的授权码。学校邮箱填写服务商的 SMTP 设置，或使用其 Google/Microsoft 授权；能否连接受学校管理员策略和服务器可达性影响。

代码覆盖这些连接方式，真实账号兼容性仍需配置后验证。当前没有实现收件箱同步或群发；SMTP 是否保存“已发送”副本取决于邮箱服务商。

## 下一步优先级

1. **公开开放注册前**：接站点专用的账号验证/恢复邮件，补举报、管理删除与发布者身份核验。当前帖子身份明确为未核验。
2. **正式邮箱联调**：完成 Google/Microsoft 授权应用配置，并用各类真实邮箱逐一验证。真实发送需由用户在工作台确认。
3. **需要多人持续使用时**：目前会话和 OAuth 刷新锁沿用单进程方案；需要多进程部署时再迁移共享会话/锁。定期备份数据库与单独保管加密密钥。
4. **AI 预算**：先保留免费模板和可选 AI 邮件，不新增全站自动 AI 调用或付费系统。有用户使用量后，再根据实际成本设置额度和收费。邮件与项目匹配分别由 `ENABLE_AI_DRAFTING`、`ENABLE_MATCH_AI` 控制，模板和本地规则本身不产生 AI 调用费。

导师认证、实验室认领、结构化候选列表、经验帖申请字段和讨论采纳属于 P1。只有达到至少 30 名试用学生、100 张真实申请卡，且多数测试者完成第二次申请动作后再建设；合作撮合、仪器调配与论文选题工作台属于更后的 P2，当前均未实现。
